## Mejoras propuestas (priorizadas — para el equipo de código)

1. **[conversation] Prompting / Nucleo (Flash)** — Añadir una instrucción explícita de 'borrado de historial de output' o 'no repetir saludos previos' entre turnos.
   · _por qué_: Se observa contaminación de turnos anteriores (repetición de 'Hola Alex' y de frases sobre widgets fallidos) en las respuestas actuales.
2. **[conversation] Brain Memory / Contexto Semántico** — Aumentar el 'weight' o prioridad de la memoria conversacional reciente sobre la literalidad del último transcript de STT cuando este contiene palabras desconocidas.
   · _por qué_: Ante 'genoc' o 'heina', el asistente abandona el flujo natural (hablar del finde/reloj) para entrar en un bucle de error sobre entidades inexistentes, demostrando falta de robustez semántica.
3. **[conversation] Interrupción / VAD** — Implementar 'barge-in' early o detener la generación de TTS si el usuario empieza a hablar durante la latencia de 4s.
   · _por qué_: La latencia media es de casi 4 segundos, lo cual es excesivo para una charla informal; el usuario intenta corregir pero zaelar ya está procesando una respuesta obsoleta.
