## Mejoras propuestas (priorizadas — para el equipo de código)

1. **[paste] brain prompt/chain-of-thought** — Añadir una instrucción explícita de post-procesado: 'Si el usuario pide un resumen en N líneas, recorta la salida para cumplir estrictamente con esa restricción y evita repetir la misma frase dos veces.'
   · _por qué_: Se observó duplicación verbal ('Resumen: ... Resumen: ...') que rompe la naturalidad y falla la restricción de longitud.
2. **[paste] nlp/intent handler** — Priorizar la detección de comillas o contexto 'pasteado' para aislar el contenido del texto pegado. Si el usuario pega texto que contiene una pregunta ('Qué tiempo hace'), el bot debe ignorarlo a menos que el usuario lo active explícitamente.
   · _por qué_: El bot ejecutó una búsqueda de tiempo ('Madrid') basándose en ruido dentro del texto pegado en lugar de centrarse solo en el resumen solicitado.
3. **[paste] frontend/brain pipe** — Verificar el buffer de recepción del data-channel para asegurar que payloads grandes no se cortan antes de llegar al prompt del LLM (ej. enviar chunking o streaming completo).
   · _por qué_: La traza muestra 'input recortado' y texto final incompleto, lo que indica pérdida de información del usuario.
