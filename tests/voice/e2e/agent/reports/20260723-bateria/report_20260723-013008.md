## Mejoras propuestas (priorizadas — para el equipo de código)

1. **[archivos] Brain/Prompting (Instrucciones de Sistema)** — Añadir una regla negativa explícita: 'NO repitas el texto pegado por el usuario ni el contenido de notas anteriores como filler. Responde únicamente a la intención específica del último turno.'
   · _por qué_: El bot está absorbiendo el ruido del contexto ('sacaste al perro...') y repitiéndolo, reduciendo la naturalidad y ensuciando la conversación.
2. **[archivos] FlashBrain/Memory Management** — Prohibir la alucinación de detalles en las respuestas. Si se recibe un 'susurro' system note que implica una acción futura (ej. buscar lugares), NO debe incluirse texto descriptivo de esa acción en la respuesta verbal hasta que la acción se haya completado y validado.
   · _por qué_: Zaelar inventó una 'cena sorpresa' que no estaba en el prompt ni en la memoria, probablemente confundido por el ruido o por el susurro interno.
3. **[archivos] Filtro de Output (Sanitización)** — Implementar un filtro que bloquee la salida de texto si coincide con etiquetas de sistema como '[SISTEMA]' o si el texto se genera inmediatamente después de un log de 'susurro' sin procesamiento.
   · _por qué_: El usuario escuchó literalmente el texto de instrucción interna ('Estoy buscando los mejores lugares...'), lo cual es un error crítico de experiencia.
