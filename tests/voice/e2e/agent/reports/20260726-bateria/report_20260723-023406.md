## Mejoras propuestas (priorizadas — para el equipo de código)

1. **[navegador_una_tarea] Cerebro / Worker (State Management)** — Implementar un patrón de 'Update or Create' estricto para la tarea de navegador. Si el usuario aclara parámetros sobre un tema activo, el Worker debe emitir un evento de actualización sobre la EXISTENTE 'navegador::t1', nunca lanzar 'navegador::t2'.
   · _por qué_: El requisito principal ('REGLA DURA') es mantener UNA sola tarjeta. Actualmente crea instancias paralelas (t1, t2) fragmentando la atención y el contexto.
2. **[navegador_una_tarea] Prompting / Cerebro (Ingest)** — Instruir al 'Nucleo(flash)' para que priorice y reconozca explícitamente las negaciones/correcciones del usuario (ej. 'No, no me importa la marca') como comandos de REFINADO inmediato, no como nueva input independiente.
   · _por qué_: El usuario corrigió la búsqueda y el bot pareció obviarlo o procesarla tarde, provocando una búsqueda genérica inicial y fallando al objetivo de búsqueda filtrada.
3. **[navegador_una_tarea] Latencia / Performance** — Optimizar el 'Flash layer' y la ruta de completado para reducir latencias por encima de 3500ms.
   · _por qué_: Una media de 3.5s con picos de 4.2s ralentiza el flujo, haciendo que los rellenos de espera ('Vale, a ver...') se sientan lentos y exponiendo la percepción de 'pensamiento' artificial.
