## Mejoras propuestas (priorizadas — para el equipo de código)

1. **[conversation] brain memory / conversational history** — Implementar un bloqueo lógico o 'debounce' en el cerebro para evitar que el saludo por defecto se ejecute si ya se ha saludado 2 veces en los últimos 60 segundos.
   · _por qué_: Zaelar repite el salvo 'Hola Alex, soy zaelar...' en bucle cuando hay ruido o confusiones, lo que percibe el usuario como un fallo de identidad o atención.
2. **[conversation] logic NLU / intent confidence** — Añadir una regla de 'comando de idioma' con máxima prioridad. Si se detecta 'no entiendo' + 'habla en [idioma]', forzar respuesta en ese idioma inmediatamente.
   · _por qué_: Zaelar ignoró explícitamente el pedido 'habla en español por favor', fallando el objetivo de ser un asistente útil.
3. **[conversation] prompt persona / few-shotting** — Incluir ejemplos de confirmación-distinta-de-repetición en el prompt del sistema. Si el usuario dice 'Gracias por la info', el bot debe responder con 'De nada' o cambiar de tema, no releer la info.
   · _por qué_: Zaelar repitió la lista de citas en el último turno aunque el usuario ya las había validado y agradecido, rompiendo la naturalidad.
4. **[conversation] interruption handling / turn endpointing** — Optimizar la detección del fin de turno (VAD/End-pointing) para reducir latencias por encima de 3500ms.
   · _por qué_: Una latencia media de 2.8s está en el límite; el pico de 3807ms hace que la conversación se sienta lenta y 'pensativa' para respuestas que deberían ser inmediatas.
