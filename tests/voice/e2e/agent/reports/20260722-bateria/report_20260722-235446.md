## Mejoras propuestas (priorizadas — para el equipo de código)

1. **[paste] brain memory/prompt injection** — Asegurar que el payload recibido por `chat/paste` se incluya explícitamente en el prompt del sistema como 'texto encolado para procesar' si el usuario dice 'Te pego...'. Desactivar heuristicas de 'resumen de día' que ignoran el input principal cuando el texto es largo.
   · _por qué_: El asistente está alucinando prioridades (recordando tareas pasadas como facturas/perro) en lugar de procesar el texto explícito pegado por el usuario.
2. **[paste] prompt engineering (system prompt)** — Instruir al modelo: 'Si el usuario introduce texto vía chat/paste, asume que ese contenido es el foco inmediato de la conversación. No pidas que 'peguen' algo que ya está en el historial de texto inmediatamente anterior.'
   · _por qué_: En el turno 3, Zaelar pide que peguen el texto ignorando que acababa de recibirlo en el turno 2, mostrando falta de atención al contexto inmediato.
3. **[paste] turn endpointing / STT boundary** — Revisar la segmentación de frases en el *nucleo(flash)*. El texto recibido se corta ('...h') en la traza, sugiriendo que el STT o el websocket envió el input de forma fragmentada o truncada.
   · _por qué_: La traza muestra `chat/paste recibido: ... Además h`, lo que indica un procesamiento prematuro de un input incompleto o un fallo en el envío del payload completo por el canal de datos.
