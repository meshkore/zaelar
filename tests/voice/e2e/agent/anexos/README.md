# tester/anexos — anexos del sistema de testing del bot

Anexos LEGIBLES del arnés de testing (la lógica ejecutable vive en `tester/`). Playbook canónico:
**`.meshkore/docs/ops/zaelar-testing.md`** ("lanza un test del bot").

- **`catalogo-escenarios.md`** — lista de casos de uso que probamos (por capacidad y prioridad), alineada con
  `tester/scenarios.py` en el Paso 0 del playbook.

Los **informes archivados** por día no van aquí, van en **`tester/reports/<YYYYMMDD>-<desc>/`** (histórico
consultable; ver el README de esa carpeta).
