**Todo lo que necesitas está en [`CLAUDE.md`](CLAUDE.md). Léelo entero antes de tocar nada.**

contexto, cómo se prueba y las reglas duras. No hay una versión distinta para cada herramienta — había cinco
copias del mismo fichero (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`, `.clinerules`, `.cursor/rules/`), de 400 KB
cada una, y lo único que hacían era desincronizarse: el 2026-09-15 cuatro de ellas iban ya una tanda por
detrás, cada una lista para que quien la leyera trabajara con reglas viejas.

Se llama `CLAUDE.md` porque es el que Claude Code carga solo, y es el asistente con el que se desarrolla este
proyecto. Nada de lo que hay dentro es específico de Claude.
