## Mejoras propuestas (priorizadas — para el equipo de código)

1. **[search] Brain LLM / Nucleo(flash)** — Implementar un filtro estricto de 'deduplicación de subsentencias' antes de enviar el prompt a TTS.
   · _por qué_: El modelo generó dos variaciones de la misma respuesta ('La última carrera fue...' y 'Tienes razón, busco ahora...') y las concatenó, resultando en una repetición robótica y confusa.
2. **[search] Data-channel / Input Router** — Priorizar la entrada de texto (paste/chat) sobre el estado de 'saludo memory-aware' si se recibe durante el kickoff.
   · _por qué_: Zaelar ignoró la corrección por texto del tester en el turno 0 y repitió el saludo de memoria, demostrando falta de integración multicanal en tiempo real.
3. **[search] RAG / Knowledge Base (F1 facts)** — Validar factualidad del último año deportivo en el contexto recuperado para evitar alucinaciones de nombres (ej. 'Karen' en lugar de 'McLaren' o 'Norris').
   · _por qué_: El asistente inventó un nombre ('Karen') relacionado con el campeonato, lo que destruye la confianza en la información proporcionada.
4. **[search] Search Tool / Performance** — Reducir timeout o implementar 'streaming search' para cortar la latencia a <3000ms para búsquedas simples.
   · _por qué_: 8 segundos de silencio para una búsqueda factual 'light' hacen que la experiencia se sienta rota.
