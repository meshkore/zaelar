## Mejoras propuestas (priorizadas — para el equipo de código)

1. **[memory] Brain / LLM Prompt** — Implementar un bloque estricto de 'repetición de contexto' en el prompt del sistema: 'Nunca repitas saludos previos ni chunks de audio antiguos. Responde SOLO al nuevo input del usuario.'
   · _por qué_: Zaelar está reproduciendo audio cacheado ('Hola Alex...') en medio de la conversación, lo que rompe la ilusión de naturalidad y confunde al flujo.
2. **[memory] Retrieval Augmented Generation (RAG) / Memory Injection** — Aumentar el límite de caracteres en el in-context prompt o usar un resumen de la memoria ('memoria de trabajo') en lugar de cortar el input (→1600 chars observado).
   · _por qué_: La traza muestra 'input recortado'. Esto provoca que el LLM pierda el hecho recién guardado sobre el coche, generando respuestas contradictorias ('No me has dicho la ubicación').
3. **[memory] Tool Calling / Action Router** — Forzar una llamada a función o 'tool' cuando el usuario pida realizar una búsqueda ('Podrías buscar...'). El LLM no debe 'chatear' sobre la búsqueda, debe intentar ejecutarla.
   · _por qué_: El usuario pidió buscar la ubicación y zaelar solo verbalizó que no la tenía, sin intentar realizar una acción de búsqueda o consulta de mapas.
