## Mejoras propuestas (priorizadas — para el equipo de código)

1. **[complex_idea] Deber de Turno / Prompt de Salida** — Implementar un filtro estricto que evite incluir la transcripción del usuario inmediatamente anterior o el 'replay' del prompt en la respuesta final del TTS.
   · _por qué_: Se observó eco de la pregunta del usuario en la respuesta de zaelar ('¿Prefieres algo en el centro...?'), lo que suena robótico y confunde el contexto.
2. **[complex_idea] Core - Router / Navegador** — Revisar el binding de entidades entre el cerebro ('SlowBrain') y el FlashBrain. Asegurar que si se selecciona una entidad (Ivalet Central) en el contexto de tarea, se invalide o purgue la entidad competidora (La Arabidan) antes de generar la respuesta de texto.
   · _por qué_: Se detectó una respuesta compuesta contradictoria ('Ivalet Central... ¿busco disponibilidad para La Arabidan?') indicando que el modelo mantuvo dos entidades en competencia simultáneamente.
3. **[complex_idea] Control de Versiones / Coherencia Cognitiva** — Sincronizar los tiempos de renderizado de la UI con el prompt de contexto. La acción visual (widget:data) llega al frontend antes o independientemente de que el modelo verbal 'acepte' el dato, causando desconexión entre lo que zaelar dice ('no encuentro') y lo que hace (muestra datos).
   · _por qué_: La traza muestra que la herramienta de navegador está activa y generando datos, pero el modelo verbal dice 'no encuentro' o parece no estar alineado con la información recuperada.
