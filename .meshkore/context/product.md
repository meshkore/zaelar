# Product

**Who**: ricart — one owner-user first; multi-user and family sharing are future, not current design drivers.

**Value**:
- Voice-first daily companion: talk, it answers in under a second and remembers across sessions
- Visual canvas: widgets (agenda coach, weather/search, browser) appear when voice alone is not enough
- Own brain, own memory: Colmena (`nucleo/`) + SQLite memory — private, local, no external agent in the loop
- Proactive: own cron/scheduler + sparks surface reminders without being asked

**Anti-product**:
- NOT a MeshKore network agent — independent product; MeshKore link is a connector, not the core
- NOT a SaaS or multi-tenant cloud product — local-first; cloud demo is parked
- NOT a general developer IDE — widgets are generated by exactly one scoped agent per task
- NOT a reasoning-on-every-turn system — the voice path is non-reasoning by hard rule
